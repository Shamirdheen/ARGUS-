Which position drives itThe single worst health factor across the watched wallet. Never an average: an average hides the position that is about to break.
When it changesGetting worse: immediately. Getting better: only after 60 seconds at the new tier, so a wick does not make the tab flicker.
Tab titleAlways carries the number, so state never depends on colour: “(!) 1.04x · Act now”. Safe tabs say “Argus · 7 positions”.
No animationFavicons cannot pulse reliably across browsers. Critical is shown by inverting the whole tile to terracotta instead.
No walletLanding, docs and logged-out pages use the static 13-dot Hundred mark.
SizesDynamic: SVG icon, regenerated per tier. Static fallbacks: 16, 32 and 48 px PNG, 180 px apple-touch-icon (Hundred, never the risk eye). Test Safari separately: SVG favicon support there has been inconsistent.
Implementation
// One function, one job: worst health factor in, favicon + title out.
const tierOf = (hf) => hf < 1.2 ? "critical" : hf < 1.5 ? "warning" : hf < 2 ? "watch" : "safe";

export function setLivingFavicon(worstHf, positionCount) {
  const tier = tierOf(worstHf);
  document.querySelector('link[rel="icon"]').href = `/favicon/${tier}.svg`;
  document.title = tier === "critical" ? `(!) ${worstHf.toFixed(2)}x · Act now`
    : tier === "safe" ? `Argus · ${positionCount} positions`
    : `${worstHf.toFixed(2)}x · Argus`;
}
